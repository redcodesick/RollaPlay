### Icon and in-app brand mark redeploy

The Windows app/installer icon and the in-app `BrandMark` (sidebar, profile, About and setup) now use the user-provided Rolla cat-headphones artwork. `pnpm tauri icon` generated the Windows icon set in `src-tauri/icons/` (`32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.ico` with 16/24/32/48/64/256 entries, plus `icon.png` and `icon-1024.png`); non-Windows targets generated by the CLI were removed. `src-tauri/tauri.conf.json` already referenced those filenames, so no config change was needed and future releases inherit the icon automatically. The UI mark used an optimized 256×256 transparent PNG at `public/rolla-mark.png`, rendered at 82% inside the existing red `.rolla-mark` tile; `src/ui.tsx` and the three `img` sizing rules in `src/redesign.css` replaced the inline `R` SVG. The installed executable was checked with `ExtractAssociatedIcon`: its 32×32 icon matches the new `icon.ico`, not the previous `R` artwork.

Because every 0.3.2 asset still had zero downloads at the time, the version was **not** bumped. The installers were rebuilt locally with `pnpm tauri build --ci` using the existing signing key and uploaded with `--clobber` at 2026-11-25T10:50Z. `latest.json` was regenerated from those local signed artifacts, keeping the original `pub_date` and release notes. Downloaded copies from GitHub were hash-verified against the local artifacts; the manifest signatures match the uploaded `.sig` files. Later refinements (full-tile mark and per-machine NSIS) were moved to 0.3.3 because 0.3.2 had started receiving downloads and must not be overwritten.
